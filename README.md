# BotFlow Exchange

A single-file token swap interface for WBOT and USDT on BOT Chain (chain ID 677), routed through the BDEX V3 contracts.

## Features
- Connect an EVM wallet (MetaMask, OKX, Bitget, TokenPocket)
- Best-price quote across fee tiers
- Slippage control and minimum received
- Switches or adds BOT Chain automatically

## Run
Open `index.html` in a browser, or host it on any static host (Vercel, GitHub Pages).

## Notice
BotFlow Exchange is an independent interface and is not affiliated with BOT Chain. Verify contract addresses on https://scan.botchain.ai before use.
